## What it does

The program writes the entrant's own make.fun username — one word,
nothing else — to `/output/entry.txt`, then stops.

The username is **`vins12`**: 6 characters, one word, no spaces, no
newline, no explanation, no link, no pitch. It is Vins's genuine
make.fun handle (`@vins12`), short enough to stick after one look.

## How to run

```sh
python3 main.py
```

It writes exactly `vins12` to `/output/entry.txt` and exits 0.
Pure Python standard library, no network, no input file, deterministic:
every run writes the same bytes.
